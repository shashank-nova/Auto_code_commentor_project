# Auto_code_commentor_project
The Auto Code Commentor is a Python-based AI tool designed to automatically generate descriptive and meaningful comments for Python functions. This project leverages natural language processing (NLP) techniques using a pre-trained T5 model (FLAN-T5-Small from Hugging Face) to understand and describe the purpose, inputs, and outputs of each function in source code.

It enhances code readability and maintainability, especially in collaborative or legacy codebases where documentation may be missing or insufficient.
